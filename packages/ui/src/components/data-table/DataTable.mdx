# Table / Data List

`DataTable` và `DataList` là wrapper dùng Ant Design `Table` và `List` cho các màn hiển thị dữ liệu lặp lại.

- Dùng `DataTable` khi cần so sánh nhiều cột, lọc, phân trang hoặc thao tác theo dòng.
- Dùng `DataList` khi nội dung thiên về mobile, card list hoặc dữ liệu ít cột.
- Server state như loading, refetch, pagination từ API nên quản lý ở app bằng TanStack Query hoặc SWR rồi truyền vào component.
