# Loading

`Loading` là icon xoay dùng chung cho trạng thái đang xử lý trong `Button`, `IconButton`, `DataTable`, `DataList` và các khu vực nội dung.

- Dùng `variant="inline"` trong button, toolbar hoặc dòng text.
- Dùng `variant="block"` khi một vùng dữ liệu hoặc panel đang tải.
- Dùng `tone="primary"` trên nền orange primary vì spinner cần giữ màu đen theo chuẩn app.
- Mặc định chỉ hiển thị icon xoay, không hiển thị chữ loading.
