# FormField

`FormField` là wrapper chung cho label, helper text, error message và aria wiring của form control. Component này không khóa vào một input cụ thể, nên có thể dùng với `Input`, `PasswordInput`, `Textarea`, Select hoặc custom control.

## Cách Dùng

`children` có thể là React node bình thường hoặc render function. Khi dùng render function, component truyền `fieldProps` gồm `id`, `aria-describedby`, `aria-invalid` và `aria-required` để gắn vào control bên trong.
