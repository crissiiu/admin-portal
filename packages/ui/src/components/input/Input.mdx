# Input

`Input` là wrapper cho Ant Design Input, dùng cho text field cơ bản trong form và bộ lọc. Component hỗ trợ `label`, `helperText`, `error`, `required`, prefix/suffix icon, disabled, status và các size của AntD.

## Khi Nào Dùng

- Dùng `Input` cho text, email, search hoặc numeric input đơn giản.
- Dùng `PasswordInput` cho mật khẩu.
- Dùng `Textarea` cho nội dung nhiều dòng.
- Dùng `error` khi cần hiển thị lỗi validation; component tự set `status="error"` và `aria-invalid`.
- Dùng `helperText` cho hướng dẫn ngắn, không đặt nội dung quá dài dưới field.
